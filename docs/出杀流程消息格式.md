## 1. 出牌阶段

**触发时机**：轮到自己出牌时，告知前端展示可选手牌，等待玩家决定是否出牌。

### 1.1 Server → All (excl. current)：PLAYER_THINKING

广播给**除自己外的其他玩家**，显示"当前玩家正在思考"。

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| type | String | `"PLAYER_THINKING"` | 消息类型 |
| playerId | String | `"player_001"` | 正在决策的玩家 ID |
| timeout | Number | `15` | 超时秒数（前端倒计时用） |
| description | String | `"出牌阶段思考中"` | 显示文案 |

```json
{
  "type": "PLAYER_THINKING",
  "playerId": "player_001",
  "timeout": 15,
  "description": "出牌阶段思考中"
}
```

### 1.2 Server → Current：ACTION_DECISION（出牌决策）

发送给当前玩家，要求选择一张手牌后点击"确定"或"回合结束"。

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| type | String | `"ACTION_DECISION"` | 消息类型 |
| timeout | Number | `15` | 前端倒计时秒数 |
| description | String | `"出牌阶段，请选择一张卡牌"` | 提示文案 |
| actions | Array | `[{"text":..., "value":..., "type":...}]` | 按钮列表 |
| handSelectable | Boolean | `true` | 是否允许选牌 |
| handSelectMode | String | `"single"` | 选牌模式：`single` / `multiple` |
| targetSelectable | Boolean | `false` | 是否允许选目标（出牌阶段不允许） |

**actions 元素结构：**

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| text | String | `"确定"` | 按钮显示文字 |
| value | String | `"confirm"` / `"end_turn"` | 点击后返回的值 |
| type | String | `"default"` / `"primary"` | 按钮样式类型 |

```json
{
  "type": "ACTION_DECISION",
  "timeout": 15,
  "description": "出牌阶段，请选择一张卡牌",
  "actions": [
    {"text": "确定", "value": "confirm", "type": "default"},
    {"text": "回合结束", "value": "end_turn", "type": "primary"}
  ],
  "handSelectable": true,
  "handSelectMode": "single",
  "targetSelectable": false
}
```

## 2. 选择目标

**触发时机**：玩家选中一张【杀】并点击"确定"后，如果该牌需要指定目标，进入选目标阶段。

### 2.1 Server → Current：ACTION_DECISION（选择目标）

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| type | String | `"ACTION_DECISION"` | 消息类型 |
| timeout | Number | `15` | 前端倒计时秒数 |
| description | String | `"请选择【杀】的目标"` | 提示文案 |
| actions | Array | 确定/取消按钮 | 按钮列表 |
| handSelectable | Boolean | `false` | 选目标阶段不可选牌 |
| targetSelectable | Boolean | `true` | 是否允许选目标 |
| selectableTargetIds | Array\<String\> | `["player_002", "player_003"]` | 可选目标玩家 ID 列表 |
| targetSelectMode | String | `"single"` | 选择模式：`single` / `multiple` |
| selectedCardIds | Array\<String\> | `["10042"]` | **已选卡牌 ID**（前端据此保持卡牌浮起） |

```json
{
  "type": "ACTION_DECISION",
  "timeout": 15,
  "description": "请选择【杀】的目标",
  "actions": [
    {"text": "确定", "value": "play_sha", "type": "primary"},
    {"text": "取消", "value": "cancel", "type": "primary"}
  ],
  "handSelectable": false,
  "targetSelectable": true,
  "selectableTargetIds": ["player_002", "player_003"],
  "targetSelectMode": "single",
  "selectedCardIds": ["10042"]
}
```

## 3. 目标连线（TARGET_LINE）

**触发时机**：出牌方选完目标后、第一张 `CARD.MOVE` 之前广播。前端据此渲染使用玩家到目标玩家之间的射线/链式动画。

### 3.1 Server → All：TARGET_LINE

广播给**房间内所有玩家**。

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| type | String | `"TARGET_LINE"` | 消息类型 |
| sourceId | String | `"player_001"` | 使用牌（发起者）的玩家 ID |
| sourceName | String | `"关羽"` | 使用牌玩家名 |
| targets | Array | `[{"targetId":"player_002","targetName":"赵云"}]` | 目标玩家集合 |
| chain | Boolean | `false` | 是否链式连线 |
| cardDefId | String | `"sha"` | 触发的卡牌 ID（扩展字段，前端可用于不同颜色/样式的连线） |

**targets 元素结构：**

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| targetId | String | `"player_002"` | 目标玩家 ID |
| targetName | String | `"赵云"` | 目标玩家名 |

**chain 行为定义：**

| chain 值 | 前端渲染行为 |
|----------|-------------|
| `false` | 从 `source` 到每个 `targets` 分别渲染一条独立射线（如【杀】、【决斗】） |
| `true` | `source` → `targets[0]` → `targets[1]` → ... 链式连线（如【铁索连环】） |

```json
{
  "type": "TARGET_LINE",
  "sourceId": "player_001",
  "sourceName": "关羽",
  "targets": [
    {"targetId": "player_002", "targetName": "赵云"}
  ],
  "chain": false,
  "cardDefId": "sha"
}
```

## 4. 使用牌生命周期（CARD.MOVE）

**触发时机**：目标选定后，【杀】牌从手牌移到牌桌中央，触发 `CARD.USE` 事件。

### 4.1 Server → All：CARD_MOVE（手牌 → 牌桌中央）

广播给**房间内所有玩家**，通知某张牌从某位置移到目标位置。

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| type | String | `"CARD_MOVE"` | 消息类型 |
| playerId | String | `"player_001"` | 所属玩家 ID |
| playerName | String | `"关羽"` | 所属玩家名 |
| cardInstanceId | Number | `10042` | 卡牌实例 ID |
| cardDefId | String | `"sha"` | 卡牌定义 ID |
| suit | String | `"SPADE"` | 花色代码（SPADE/HEART/CLUB/DIAMOND） |
| suitName | String | `"♠"` | 花色显示名 |
| point | Number | `7` | 点数 |
| from | String | `"HAND"` | 来源区域（HAND / TABLE_CENTER / DISCARD_PILE / EQUIP 等） |
| to | String | `"TABLE_CENTER"` | 目标区域（TABLE_CENTER / DISCARD_PILE / HAND / EQUIP 等） |

```json
{
  "type": "CARD_MOVE",
  "playerId": "player_001",
  "playerName": "关羽",
  "cardInstanceId": 10042,
  "cardDefId": "sha",
  "suit": "SPADE",
  "suitName": "♠",
  "point": 7,
  "from": "HAND",
  "to": "TABLE_CENTER"
}
```

## 5. 闪响应阶段

**触发时机**：`CARD.USE.ACTIVE` 事件发布后，`ShanCard` 检测到使用的牌是【杀】，触发目标的闪响应流程。

### 5.1 Server → Target：HAND_STATUS（标记手牌可用性）

发送给**被杀的玩家**（目标玩家），标记哪些牌可选（高亮）、哪些不可选（灰显+原因）。

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| type | String | `"HAND_STATUS"` | 消息类型 |
| cards | Array | `[...]` | 手牌状态列表 |
| phase | String | `"PLAY"` | 当前阶段 |
| isMyTurn | Boolean | `false` | 是否为该玩家的回合 |

**cards 元素结构：**

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| instanceId | Number | `10051` | 卡牌实例 ID |
| status | Number | `0` / `1` | 状态码：`0`=可选(PLAYABLE)，`1`=不可选(NOT_SELECTABLE) |
| statusName | String | `"PLAYABLE"` / `"NOT_SELECTABLE"` | 状态名 |
| reason | String | `"不可使用"` | 不可选时的原因（可选时 null） |

```json
{
  "type": "HAND_STATUS",
  "cards": [
    {"instanceId": 10050, "status": 1, "statusName": "NOT_SELECTABLE", "reason": "不可使用"},
    {"instanceId": 10051, "status": 0, "statusName": "PLAYABLE", "reason": null},
    {"instanceId": 10052, "status": 1, "statusName": "NOT_SELECTABLE", "reason": "不可使用"}
  ],
  "phase": "PLAY",
  "isMyTurn": false
}
```

### 5.2 Server → All (excl. target)：PLAYER_THINKING（目标玩家思考中）

广播给**除目标外的其他玩家**。

| 字段 | 类型 | 值示例 |
|------|------|--------|
| type | String | `"PLAYER_THINKING"` |
| playerId | String | `"player_002"` |
| timeout | Number | `15` |
| description | String | `"玩家【闪】思考中"` |

```json
{
  "type": "PLAYER_THINKING",
  "playerId": "player_002",
  "timeout": 15,
  "description": "玩家【闪】思考中"
}
```

### 5.3 Server → Target：ACTION_DECISION（选闪）

发送给**被杀的玩家**，要求从手牌中选择一张【闪】。

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| type | String | `"ACTION_DECISION"` | 消息类型 |
| timeout | Number | `15` | 倒计时秒数 |
| description | String | `"【关羽】对你使用一张【杀】，请使用一张【闪】"` | 提示文案 |
| actions | Array | 取消按钮 | 按钮列表 |
| handSelectable | Boolean | `true` | 允许选牌 |
| handSelectMode | String | `"single"` | 单选 |
| targetSelectable | Boolean | `false` | 不需要选目标 |

```json
{
  "type": "ACTION_DECISION",
  "timeout": 15,
  "description": "【关羽】对你使用一张【杀】，请使用一张【闪】",
  "actions": [
    {"text": "取消", "value": "cancel", "type": "primary"}
  ],
  "handSelectable": true,
  "handSelectMode": "single",
  "targetSelectable": false
}
```

> **注意**：此阶段前端应配合 `HAND_STATUS` 的消息，只有【闪】高亮可选，其余牌灰显不可点击。

### 5.4 Server → All (excl. target)：PLAYER_THINKING（确认阶段）

如果玩家选了一张【闪】，后端会再次广播思考状态，然后进入确认阶段。

```json
{
  "type": "PLAYER_THINKING",
  "playerId": "player_002",
  "timeout": 15,
  "description": "玩家【闪】思考中"
}
```

### 5.5 Server → Target：ACTION_DECISION（确认出闪）

发送给**被杀的玩家**，显示已选的【闪】，确认是否打出。

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| type | String | `"ACTION_DECISION"` | 消息类型 |
| timeout | Number | `15` | 倒计时秒数 |
| description | String | `"确定要使用【闪】来抵消【杀】吗？"` | 提示文案 |
| actions | Array | 确定/取消按钮 | 按钮列表 |
| handSelectable | Boolean | `false` | 确认阶段不能重新选牌 |
| targetSelectable | Boolean | `false` | 不需要选目标 |
| selectedCardIds | Array\<String\> | `["10051"]` | **已选卡牌 ID**（前端据此保持卡牌浮起） |

```json
{
  "type": "ACTION_DECISION",
  "timeout": 15,
  "description": "确定要使用【闪】来抵消【杀】吗？",
  "actions": [
    {"text": "确定", "value": "confirm", "type": "primary"},
    {"text": "取消", "value": "cancel", "type": "primary"}
  ],
  "handSelectable": false,
  "targetSelectable": false,
  "selectedCardIds": ["10051"]
}
```

> **用户交互**：
> - **确定** → 出闪成功，【杀】被抵消进入弃牌堆
> - **取消** → 回到选牌阶段 [5.3](#53-server--targetaction_decision选闪)，重新选牌
> - **超时** → 视为放弃出闪，【杀】效果继续执行
> - **选牌阶段取消/超时** → 视为放弃出闪

### 5.6 Server → All：CARD_MOVE（闪移入牌桌中央）

如果玩家确认出闪，闪牌从手牌移到牌桌中央。

```json
{
  "type": "CARD_MOVE",
  "playerId": "player_002",
  "playerName": "赵云",
  "cardInstanceId": 10051,
  "cardDefId": "shan",
  "suit": "HEART",
  "suitName": "♥",
  "point": 3,
  "from": "HAND",
  "to": "TABLE_CENTER"
}
```

## 6. 造成伤害（HIT）

**触发时机**：如果目标**没有出闪**（放弃/超时），【杀】的效果命中目标，造成伤害后广播结果。

### 6.1 Server → All：HIT（伤害结果）

广播给**房间内所有玩家**。

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| type | String | `"HIT"` | 消息类型 |
| sourceId | String | `"player_001"` | 伤害来源玩家 ID（null=系统/环境） |
| sourceName | String | `"关羽"` | 伤害来源名 |
| targetId | String | `"player_002"` | 受伤玩家 ID |
| targetName | String | `"赵云"` | 受伤玩家名 |
| damage | Number | `1` | 伤害点数 |
| remainingHp | Number | `3` | 受伤后当前体力值 |
| maxHp | Number | `4` | 最大体力值 |
| alive | Boolean | `true` | 玩家是否存活 |

```json
{
  "type": "HIT",
  "sourceId": "player_001",
  "sourceName": "关羽",
  "targetId": "player_002",
  "targetName": "赵云",
  "damage": 1,
  "remainingHp": 3,
  "maxHp": 4,
  "alive": true
}
```

## 7. 牌移入弃牌堆（CARD.MOVE）

**触发时机**：牌效果结束后，【杀】和【闪】（如果有出闪）分别从牌桌中央移到弃牌堆。

### 7.1 Server → All：CARD_MOVE × N（牌桌 → 弃牌堆）

每张使用过的牌各发一条。

```json
{
  "type": "CARD_MOVE",
  "playerId": "player_001",
  "playerName": "关羽",
  "cardInstanceId": 10042,
  "cardDefId": "sha",
  "suit": "SPADE",
  "suitName": "♠",
  "point": 7,
  "from": "TABLE_CENTER",
  "to": "DISCARD_PILE"
}
```

如果有出闪，再多一条闪的弃牌消息：

```json
{
  "type": "CARD_MOVE",
  "playerId": "player_002",
  "playerName": "赵云",
  "cardInstanceId": 10051,
  "cardDefId": "shan",
  "suit": "HEART",
  "suitName": "♥",
  "point": 3,
  "from": "TABLE_CENTER",
  "to": "DISCARD_PILE"
}
```

## 8. 客户端响应格式

客户端在收到 `ACTION_DECISION` 消息后，用户完成选择操作，通过 WebSocket 返回以下格式的响应：

| 字段 | 类型 | 值示例 | 说明 |
|------|------|--------|------|
| action | String | `"confirm"` / `"cancel"` / `"end_turn"` | 用户的操作类型 |
| value | String | `"confirm"` / `"play_sha"` / `"end_turn"` | 按钮携带的值（动作标识） |
| type | String | `"ACTION_RESPONSE"` | 响应类型标识 |
| selectedCardIds | Array\<String\> | `["10042"]` | 选中的手牌实例 ID 列表 |
| selectedPlayerIds | Array\<String\> | `["player_002"]` | 选中的目标玩家 ID 列表 |

```json
{
  "action": "confirm",
  "value": "confirm",
  "type": "ACTION_RESPONSE",
  "selectedCardIds": ["10042"],
  "selectedPlayerIds": ["player_002"]
}
```

### 各阶段的 action/value 对应

| 阶段 | 操作 | action | value |
|------|------|--------|-------|
| 出牌 | 出牌（有目标） | `"confirm"` | `"play_sha"` |
| 出牌 | 回合结束 | `"confirm"` | `"end_turn"` |
| 选目标 | 确认目标 | `"confirm"` | `"play_sha"` |
| 选目标 | 取消出牌 | `"cancel"` | — |
| 选闪 | 选中一张闪（进入确认） | 返回 `selectedCardIds` | 无特定 action |
| 选闪 | 取消/不出闪 | `"cancel"` | — |
| 确认出闪 | 确认出闪 | `"confirm"` | `"confirm"` |
| 确认出闪 | 取消（重选） | `"cancel"` | — |

## 附录：完整消息时序

### 场景 A：出杀 → 目标出闪（抵消）

```
出牌阶段
  Server → All(excl. A): PLAYER_THINKING("出牌阶段思考中")
  Server → A:          ACTION_DECISION(选牌出牌)

选择目标
  Server → A:          ACTION_DECISION(选目标: selectedCardIds=[杀])

CARD.USE 生命周期开始
  Server → All:        TARGET_LINE(source=A, targets=[B], chain=false)  ← 前端渲染射线
  Server → All:        CARD_MOVE(杀, HAND → TABLE_CENTER)

闪响应（ShanCard 拦截 CARD.USE.ACTIVE）
  Server → B:          HAND_STATUS(仅闪可选)
  Server → All(excl. B): PLAYER_THINKING("玩家【闪】思考中")
  Server → B:          ACTION_DECISION(选闪)
  Server → All(excl. B): PLAYER_THINKING("玩家【闪】思考中")
  Server → B:          ACTION_DECISION(确认出闪, selectedCardIds=[闪])

闪打出
  Server → All:        CARD_MOVE(闪, HAND → TABLE_CENTER)
  Server → All:        CARD_MOVE(杀, TABLE_CENTER → DISCARD_PILE)
  Server → All:        CARD_MOVE(闪, TABLE_CENTER → DISCARD_PILE)
```

### 场景 B：出杀 → 目标不出闪（命中）

```
出牌阶段
  Server → All(excl. A): PLAYER_THINKING("出牌阶段思考中")
  Server → A:          ACTION_DECISION(选牌出牌)

选择目标
  Server → A:          ACTION_DECISION(选目标: selectedCardIds=[杀])

CARD.USE 生命周期开始
  Server → All:        TARGET_LINE(source=A, targets=[B], chain=false)  ← 前端渲染射线
  Server → All:        CARD_MOVE(杀, HAND → TABLE_CENTER)

闪响应（ShanCard 拦截 CARD.USE.ACTIVE）
  Server → B:          HAND_STATUS(仅闪可选)
  Server → All(excl. B): PLAYER_THINKING("玩家【闪】思考中")
  Server → B:          ACTION_DECISION(选闪)
  → B 取消/超时，不出闪

造成伤害
  Server → All:        HIT(A 对 B 造成 1 点伤害)

弃牌
  Server → All:        CARD_MOVE(杀, TABLE_CENTER → DISCARD_PILE)
```
